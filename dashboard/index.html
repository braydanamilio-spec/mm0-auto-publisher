➕ Connect / add channel
Click → sign in to that channel's Google → grant once → token saved. No GitHub Secrets needed.
🔗 Cách kết nối / khắc phục
  1. Chạy python src/auth_setup.py cho mỗi kênh → lấy refresh token YouTube.
  2. Nạp token vào GitHub → Settings → Secrets (theo tên trong channels.yaml).
  3. Facebook: lấy Page long-lived token (xem SETUP.md bước 6).
  4. Trạng thái bên trên tự cập nhật sau mỗi lần đăng / mỗi lần chạy thống kê (6 giờ).
➕ Connect a storage Drive account (+15GB free each)
Click → sign in Drive account → grant → auto-creates store folder + saves token. Combine many = 150GB/1TB.
🧹 Cleanup settings
💾 Hồ chứa (tài khoản Drive)
📂 Duyệt file trong kho (xem · đổi tên · xoá tay)
🧹 Dọn dẹp
  1. keep = giữ tất cả (Google One) · delete = xoá file đã đăng cũ · archive = chuyển sang kho lạnh.
  2. Chỉnh trong config/storage.yaml → cleanup.mode / trigger / keep_days.
  3. Thủ công: python src/cleanup.py --now hoặc Actions → MM0 Storage Cleanup.
⚙️ Cấu hình hệ thống
📅 Thư viện template gói đăng bài
💾 Sao lưu & khôi phục cấu hình
🔒 Vì bảo mật, file KHÔNG chứa token/API key (giống mọi SaaS lớn — không giữ token dạng file để tránh lộ). File lưu danh sách kết nối + cấu hình (kênh · Page · tài khoản kho · template · dọn dẹp) để anh khôi phục nhanh. Token thì bấm Kết nối lại 1 lần (an toàn hơn giữ file token).
🚀 Bulk schedule / publish
Operates on videos already in your Drive queue. “Publish now” = next cron run (~30 min) posts it. Posted videos aren’t touched.

📘 Facebook Pages
Facebook tách riêng YouTube (không cùng Gmail). Kết nối 1 lần lấy hết Page bạn quản lý; đăng/lịch FB quản lý riêng tại đây.
🔗 Gắn kênh YouTube → Facebook Page
Set 1 lần. Video của kênh sẽ tự đăng lên Page đã gắn (+ Instagram nếu Page có IG, chỉ short). Bỏ trống = không đăng FB/IG cho kênh đó. Cơ chế đăng FB/IG tách riêng YouTube (workflow riêng, tắt máy vẫn chạy).
📘 Cần Facebook App

Kết nối FB cần Facebook Developer App (đặt secret FB_APP_ID/FB_APP_SECRET cho Worker) + quyền pages_manage_posts. Xem SETUP.md mục Facebook. Bấm Kết nối khi đã cấu hình App.
