📐 Rule & Tiêu chuẩn chất lượng
GitHub đọc theo cấu hình này
  • Hook 3s: ảnh+chart+số NGAY, giọng từ frame 0, KHÔNG card chữ tĩnh
  • Voice + karaoke (short & long) · ảnh nền thật + ảnh dẫn chứng theo lời
  • KHÔNG outro/CTA cuối · KHÔNG chồng chéo · 9:16 chuẩn
  • Chọn chủ đề: bất ngờ + data thật + 1 twist · < ngưỡng = viết lại/bỏ
⚙️ Cấu hình hệ thống
📅 Thư viện template gói đăng bài
🔗 Tiếp thị liên kết (Affiliate)
Chèn link ĐÚNG CHỖ từng nền tảng: YouTube + FB video dài → mô tả · FB Reels → bình luận ghim · Instagram → "link ở bio". Tự thêm UTM (đo hiệu suất, chống spam) + khai báo tiếp thị (đúng chính sách).
Áp dụng nền tảng:
🛡️ Chống spam / đúng điều khoản (tự động): xoay vòng nhiều link + CTA random mỗi bài + UTM khác nhau mỗi bài → không bị coi là "spam link giống hệt hàng loạt"; tự thêm khai báo tiếp thị; 1 link/bài; đã có giãn cách jitter + trần bài/lần chạy. Anh đặt link 1 lần — hệ tự biến hoá để an toàn.
⚠️ Instagram không thể chèn link click qua API (giới hạn Meta) — chỉ ghi "link ở bio", anh tự đặt link-in-bio. Gắn sản phẩm/tag trên Reels cần Facebook Shop + quyền Commerce (không tự động được). Nên dùng link rút gọn thương hiệu ở dưới (không bit.ly trần) để không bị giảm reach.
🎲 Phương án 2 — Metadata dự phòng tự động
Khi video KHÔNG có metadata riêng (không tiêu đề/mô tả), hệ tự tạo tiêu đề + emoji + mô tả + hashtag + tag tổ hợp — hàng triệu biến thể, hook cao, chung chung, chuẩn USA — để vẫn đăng được. Mặc định TẮT. Video có tiêu đề riêng của anh KHÔNG bị đụng. Mỗi video 1 tiêu đề cố định (retry không đổi).
🔗 Link rút gọn thương hiệu — redirect riêng, đếm click, 100% free
Tạo link ngắn qua domain của chính anh (Cloudflare Worker) → 302 tới link affiliate + đếm click. Đây là cách các ông lớn làm (không dùng bit.ly trần dễ bị giảm reach). Dán link ngắn này vào ô "Link" ở trên. UTM vẫn được nối tự động khi đăng.
💾 Sao lưu & khôi phục cấu hình
🔒 Vì bảo mật, file KHÔNG chứa token/API key (giống mọi SaaS lớn — không giữ token dạng file để tránh lộ). File lưu danh sách kết nối + cấu hình (kênh · Page · tài khoản kho · template · dọn dẹp) để anh khôi phục nhanh. Token thì bấm Kết nối lại 1 lần (an toàn hơn giữ file token).
